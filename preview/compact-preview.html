三卡合一 · 标题栏 + 每卡大胶囊块 + 流量条（设计预览）

设计预览，非实机截图。合成测试数据，不是真实余额。本页直接执行仓库 UnicomThreeCards.js 并按返回的 DSL 构造 DOM。本页模拟 Egern 的竖直分配：组件高度固定为大号 338×354，只有“子树里含 flex 的子节点”会吸收剩余高度（spacer 不会）——这正是真机行为；早前的预览是内容自适应，所以看不出标题栏被撑高。汇总顶部为标题栏：图标用 SF Symbol（sf-symbol:simcard.fill，由 Egern 本地解析、不联网，因此不会再出现「？」占位——之前用远程 PNG 时，raw.githubusercontent.com 不可达就会渲染成问号）＋「中国联通」（半粗，字号小 11／中 12／大 13／超大 14pt），不含任何 flex、行内零留白、距第一张卡约 2pt，因此保持自然高度（约 13px）；剩余高度全部交给卡片（每卡 flex:1），流量胶囊也 flex:1 并把横条压到底部。每张卡是一个圆角大胶囊块（卡槽色低 alpha 淡染 + 1px 略亮描边，卡间留白 7pt），内部话费/语音/流量胶囊保持各自卡槽色淡染。卡槽配色蓝/紫/青；无限流量卡流量条渐变淡出并显示 ∞ 与「不限量」；有参考总量才画真实比例。浏览器字体与 Egern 原生渲染不同（同尺寸下浏览器行高略大，故中号 158pt 在浏览器里会溢出，实机以 Egern 为准）；预览里标题栏图标用 SVG 近似绘制 SF Symbol，正式 DSL 是 sf-symbol:simcard.fill；只有模块自身的 `icon` 用 CDN 上的 PNG。

① 标题栏 + 无限流量卡：什么都不用填
顶部瘦身标题栏（图标＋中国联通，无 flex 所以不会被撑高）；没有套餐总量 → 流量条向右渐变淡出、末端 ∞、标记「不限量」，绝不出现百分比

② 给有配额的卡填一次参考总量
卡2 填 500GB → 真实比例填充（剩余 120GB → 已用 76%），其余卡仍为无限淡出

③ 可调卡片顺序：CARD_ORDER=3,1,2
只改汇总显示顺序，卡槽与存储键不变；单卡组件不受影响

④ 标题栏 flex 对比（本次真正修复）
上＝旧标题栏（文字带 flex:1）→ Egern 把剩余高度分给它，标题行被撑掉半屏；下＝本次（标题无 flex、只用 spacer）→ 标题约 13px，剩余高度归三张卡

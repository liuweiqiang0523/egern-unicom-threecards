三卡合一 · 标题栏 + 每卡大胶囊块 + 流量条 DSL 设计预览

设计预览，非实机截图。合成测试数据，不是真实余额。本页直接执行仓库 UnicomThreeCards.js 并按返回的 DSL 构造 DOM；按各档真实尺寸固定高度渲染，并模拟 Egern 的竖直 flex 分配（子树里含 flex 的子节点会吸收剩余高度，spacer 不会），所以能复现真机占高问题。浏览器字体/压缩与 Egern 原生渲染不同。汇总顶部新增一行标题栏：图标用 SF Symbol（sf-symbol:simcard.fill，由 Egern 本地解析、不联网，不会再出现问号占位）＋「中国联通」（半粗，字号小 11／中 12／大 13／超大 14pt），不含任何 flex（标题行一旦含 flex，Egern 就会把剩余高度分给它、把它撑到半屏——这正是真机占高变大的根因）、行内零留白、距第一张卡约 2pt，因此保持自然高度（约 15px），剩余高度交给卡片（每卡 flex:1），可被自定义标题覆盖，SHOW_BRAND=false/off/0 时整行隐藏。每张卡仍是一个圆角大胶囊块（卡槽色低 alpha 淡染 + 1px 略亮描边，卡间留白 7pt），内部话费/语音/流量胶囊保持各自卡槽色淡染；卡片行前的卡槽色小方块保持不变，用来区分三卡。卡槽配色蓝/紫/青；无限流量卡流量条渐变淡出并显示 ∞ 与「不限量」；有参考总量才画真实比例；「卡片顺序」可调整三卡显示次序。预览里标题栏图标用 SVG 近似绘制 SF Symbol，正式 DSL 是 sf-symbol:simcard.fill；只有模块自身的 icon 用 CDN 上的 PNG。
